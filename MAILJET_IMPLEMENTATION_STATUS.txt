🛠️ TECHNICAL DETAILS
===================================================================

Mailjet API Version:     v3.1 (REST)
HTTP Method:             POST to https://api.mailjet.com/v3.1/send
Authentication:          HTTP Basic Auth (API Key : Secret Key)
Response Format:         JSON

Message Structure:
  ├─ From (Email, Name)
  ├─ To (array of recipients)
  ├─ Subject
  ├─ TextPart (plain text)
  ├─ HTMLPart (optional)
  ├─ Attachments (array with Base64Content)
  └─ CustomID (for event tracking)

Attachment Structure:
  ├─ ContentType (e.g., application/pdf)
  ├─ Filename
  └─ Base64Content

Database Timezone:       Asia/Manila
Message Storage:         chattbl table
Webhook Storage:         mailjet_webhooks table
Event Storage:           mailjet_events table (optional)

Queue Processing:        ProcessMailjetWebhook (async job)
Signature Validation:    HMAC-SHA256

===================================================================
🆘 TROUBLESHOOTING
===================================================================

Issue: "MailjetService not found"
Fix: php artisan config:cache

Issue: "Connection refused to api.mailjet.com"
Fix: Check API credentials, firewall, internet connection

Issue: "No database entries after sending"
Fix: Verify chattbl table exists, check error logs

Issue: "Webhooks not received"
Fix: Verify HTTPS URL, check signature secret, verify events selected

Issue: "Attachments fail to upload"
Fix: Check file size limits, MIME types, Base64 encoding
